# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability or an exposed credential. Use GitHub's private vulnerability reporting for this repository. Include the affected version or commit, reproduction steps, impact and any proposed mitigation.

If private vulnerability reporting is unavailable, contact the maintainers through the Opillion GitHub organization without including sensitive details in a public message.
